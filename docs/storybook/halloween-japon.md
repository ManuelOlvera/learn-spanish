# Halloween en Japón 🎃

*Halloween in Japan* — story id `halloween-japon`

> ⬜ **Not yet illustrated.** Until art exists, these pages show their
> composed emoji scenes — the story works either way.

Noah and Ava are siblings — invented characters, not real children. Ava is
the older one (eight) and must always be drawn taller than Noah (five). Universal
Studios is named in the story text, but the **pictures stay generic**: no
logos, no brand marks, and no recognisable film characters. That keeps the art
ours and keeps generators from refusing or producing trademarked figures.

Halloween is drawn **jolly, never frightening** — the audience starts at three.

Eight ready-to-paste prompts. Each block is **complete**: copy everything
between the fences, paste it into ChatGPT / the Codex app / Gemini, and save
the result. No editing, no assembly.

Two things that materially improve what comes back:

- **Generate all eight in one conversation**, in order, so the model can see
  the pictures it already made and keep Noah and Ava identical, and their height difference consistent. From prompt 2
  onward you can add *"same characters and style as the previous image"*.
- **If the tool has an aspect-ratio control, set it to 4:3 there too.** The
  prompt says so in words, but a UI setting usually beats prompt text.

**Save as** `apps/web/art-source/halloween-japon/1.png` … `8.png`, then run
`pnpm art` from the repo root. Full workflow:
[`../../apps/web/src/story-art/README.md`](../../apps/web/src/story-art/README.md).
